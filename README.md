# Relational Database Blueprint & Business Analytics Portfolio

Welcome to my SQL portfolio. This project demonstrates my ability to design relational database schemas with strict data integrity, manage records securely, and write complex queries to extract actionable business insights.

Since I focus on scalable architectures, all code here is optimized for cloud deployment and written in standard **MySQL**.

---

## 📂 Repository Structure

* **`📂 Database_Blueprint/`**: Contains the core database architecture, tables, and relationships.
  * `Clients.sql` - Core customer registry schema with data types and primary keys.
  * `Items.sql` - Product and inventory catalog schema.
  * `Purchases.sql` - Relational transactional ledger linking clients and items via Foreign Keys.
* **`📂 Business_Queries/`**: Advanced data extraction and analytical reports.
  * `My_Sample_Works.sql` - Live examples of aggregations (`GROUP BY`), data filtering (`HAVING`), sorting, and conditional profiling.

## 🛠️ Technical Skills Demonstrated
